# Chatbot Suggested Questions Implementation Plan

## Executive Summary

This document provides a comprehensive implementation plan for enhancing the chatbot's suggested questions feature. The approach prioritizes **pragmatic simplicity** over complex architecture, delivering 80% of the value with 20% of the complexity through enhanced prompt engineering, lightweight data enrichment, and rule-based templates.

**Key Principles:**
- Minimize latency impact (<50ms total)
- Minimize cost increase (<10%)
- Maximize maintainability (single service, simple logic)
- Enable rapid deployment (1-2 weeks)
- Ensure graceful degradation (works without behavioral data)

### 1.2 Current Limitations

**Technical Issues:**
- ❌ Questions are generic and not context-aware
- ❌ No consideration of user journey stage
- ❌ No personalization based on user behavior
- ❌ No fallback mechanism if LLM fails to generate questions
- ❌ No A/B testing capability

**Business Impact:**
- Low engagement with suggested questions
- Missed opportunities for conversion
- Generic user experience
- No data-driven optimization

**Rich Behavioral Data:**

1. **`visitors` table** - User profile and engagement metrics

   - `is_acknowledged` - Sales team interaction status

2. **`events` table** - Micro-interaction tracking

3. **`chat_messages` table** - Conversation history
   - `message_text` - Full conversation content
   - `sender_role` - User vs assistant messages
   - `listing_id`, `development_id` - Context tracking

## 3. Solution Architecture

### 3.1 Design Philosophy

**Pragmatic Approach:**
1. **Enhanced Prompting First** - Leverage existing LLM call with richer context
2. **Lightweight Enrichment** - Single optimized database query for user context
3. **Rule-Based Fallbacks** - Template system for reliability
4. **Hybrid Strategy** - Combine LLM intelligence with deterministic templates

```javascript
/**
 * Enriches user context with behavioral data for personalized question generation
 * @param {string} visitorId - Unique visitor identifier
 * @param {string} clientId - Client UUID
 * @returns {Promise<Object>} User context object
 */
async function enrichUserContext(visitorId, clientId) {
  if (!visitorId) {
    return {
      leadScore: 0,
      preferences: {},
      recentEvents: [],
      hasHistory: false
    };
  }

  try {
    // Single optimized query with join - ~20ms
    const { data, error } = await supabase
      .from('visitors')
      .select(`
        lead_score,
        previous_lead_score,
        tipologia,
        budget,
        development_preference,
        name,
        email,
        phone,
        events!inner(
          event_type,
          timestamp,
          listing_id
        )
      `)
      .eq('visitor_id', visitorId)
      .eq('client_id', clientId)
      .order('events.timestamp', { ascending: false })
      .limit(5) // Only recent events
      .single();

    if (error || !data) {
      console.warn(`[enrichUserContext] No data found for visitor ${visitorId}`);
      return {
        leadScore: 0,
        preferences: {},
        recentEvents: [],
        hasHistory: false
      };
    }

    // Calculate engagement trend
    const scoreTrend = data.lead_score - (data.previous_lead_score || 0);
    const engagementLevel = data.lead_score >= 70 ? 'high' : 
                           data.lead_score >= 40 ? 'medium' : 'low';

    return {
      leadScore: data.lead_score || 0,
      scoreTrend,
      engagementLevel,
      preferences: {
        tipologia: data.tipologia,
        budget: data.budget,
        development: data.development_preference
      },
      recentEvents: (data.events || []).map(e => ({
        type: e.event_type,
        listingId: e.listing_id,
        timestamp: e.timestamp
      })),
      hasContact: Boolean(data.email || data.phone),
      hasHistory: true
    };
  } catch (error) {
    console.error('[enrichUserContext] Error:', error);
    return {
      leadScore: 0,
      preferences: {},
      recentEvents: [],
      hasHistory: false
    };
  }
}
```

```javascript
/**
 * Determines engagement level from lead score
 * @param {number} leadScore - Lead score (0-100)
 * @returns {string} Engagement level: 'HIGH_ENGAGEMENT', 'MEDIUM_ENGAGEMENT', or 'LOW_ENGAGEMENT'
 */
function getEngagementLevel(leadScore) {
  if (leadScore >= 70) return 'HIGH_ENGAGEMENT';
  if (leadScore >= 40) return 'MEDIUM_ENGAGEMENT';
  return 'LOW_ENGAGEMENT';
}

/**
 * Selects appropriate question template based on context
 * @param {Object} context - Context object containing user and conversation data
 * @returns {Array<string>} Array of 3 suggested questions
 */
function selectQuestionTemplate(context) {
  const {
    leadScore = 0,
    hasListingContext = false,
    hasDevelopmentContext = false,
    lastQueryType = null,
    preferences = {}
  } = context;

  const engagementLevel = getEngagementLevel(leadScore);

  // Determine context type
  let contextType;
  if (hasListingContext) {
    contextType = 'LISTING_SPECIFIC';
  } else if (hasDevelopmentContext) {
    contextType = 'DEVELOPMENT_SPECIFIC';
  } else if (lastQueryType && QUESTION_TEMPLATES.FEATURE_INQUIRY[lastQueryType]) {
    contextType = 'FEATURE_INQUIRY';
    return QUESTION_TEMPLATES.FEATURE_INQUIRY[lastQueryType].slice(0, 3);
  } else {
    contextType = 'GENERAL_INQUIRY';
  }

  // Get base questions
  let questions = QUESTION_TEMPLATES[contextType][engagementLevel] || 
                  QUESTION_TEMPLATES.GENERAL_INQUIRY.LOW_ENGAGEMENT;

  // Personalize if preferences available
  questions = personalizeQuestions(questions, preferences);

  return questions.slice(0, 3);
}

/**
 * Personalizes question templates with user preferences
 * @param {Array<string>} questions - Base question templates
 * @param {Object} preferences - User preferences (tipologia, budget, etc.)
 * @returns {Array<string>} Personalized questions
 */
function personalizeQuestions(questions, preferences) {
  return questions.map(q => {
    let personalized = q;

    // Replace tipologia placeholder
    if (preferences.tipologia && q.includes('T{tipologia}')) {
      personalized = personalized.replace('T{tipologia}', preferences.tipologia);
    }

    // Replace budget placeholder
    if (preferences.budget && q.includes('{budget}')) {
      const formattedBudget = `€${preferences.budget.toLocaleString('pt-PT')}`;
      personalized = personalized.replace('{budget}', formattedBudget);
    }

    // Replace development placeholder
    if (preferences.development && q.includes('{development}')) {
      personalized = personalized.replace('{development}', preferences.development);
    }

    return personalized;
  });
}

/**
 * Validates LLM-generated questions for quality and relevance
 * @param {Array<string>} questions - Questions generated by LLM
 * @param {Object} context - Context for validation
 * @returns {Object} Validation result with isValid flag and filtered questions
 */
function validateLLMQuestions(questions, context) {
  if (!Array.isArray(questions) || questions.length === 0) {
    return { isValid: false, questions: [] };
  }

  // Filter out invalid questions
  const validQuestions = questions.filter(q => {
    // Must be a non-empty string
    if (typeof q !== 'string' || q.trim().length === 0) return false;

    // Must be reasonable length (10-200 characters)
    if (q.length < 10 || q.length > 200) return false;

    // Should not be generic/template-like
    const genericPatterns = [
      /^como posso ajud[aá]-?lo/i,
      /^se desejar mais/i,
      /^gostaria de saber mais/i,
      /^tem mais alguma/i
    ];
    if (genericPatterns.some(pattern => pattern.test(q))) return false;

    // Should be in first person (user perspective)
    const firstPersonIndicators = [
      /^estou/i,
      /^quero/i,
      /^gostaria/i,
      /^posso/i,
      /^tenho interesse/i
    ];
    if (!firstPersonIndicators.some(pattern => pattern.test(q))) return false;

    return true;
  });

  return {
    isValid: validQuestions.length >= 2,
    questions: validQuestions.slice(0, 3)
  };
}

/**
 * Hybrid approach: combines LLM questions with template questions
 * @param {Array<string>} llmQuestions - Questions from LLM
 * @param {Object} context - Context for template selection
 * @returns {Array<string>} Final set of 3 questions
 */
function generateHybridQuestions(llmQuestions, context) {
  const validation = validateLLMQuestions(llmQuestions, context);

  if (validation.isValid && validation.questions.length >= 3) {
    // LLM generated good questions, use them
    return validation.questions;
  }

  if (validation.isValid && validation.questions.length >= 2) {
    // LLM generated 2 good questions, add 1 template
    const templateQuestions = selectQuestionTemplate(context);
    return [
      ...validation.questions,
      templateQuestions[0]
    ].slice(0, 3);
  }

  // LLM failed or generated poor questions, use templates
  console.warn('[question-strategies] Using template fallback');
  return selectQuestionTemplate(context);
}

module.exports = {
  QUESTION_TEMPLATES,
  selectQuestionTemplate,
  personalizeQuestions,
  validateLLMQuestions,
  generateHybridQuestions,
  getEngagementLevel
};
```

```javascript
      lowerQuery.includes('valor') || lowerQuery.includes('€')) {
    return 'PRICE';
  }
  
  if (lowerQuery.includes('localização') || lowerQuery.includes('zona') || 
      lowerQuery.includes('área') || lowerQuery.includes('bairro')) {
    return 'LOCATION';
  }
  
  if (lowerQuery.includes('comodidade') || lowerQuery.includes('característica') || 
      lowerQuery.includes('piscina') || lowerQuery.includes('garagem') ||
      lowerQuery.includes('terraço')) {
    return 'AMENITIES';
  }
  
  return null;
}
```

### 7.3 A/B Testing Framework

**Implementation:**

```javascript
// File: packages/backend/src/utils/ab-testing.js

class ABTestingService {
  constructor() {
    this.experiments = new Map();
  }

  /**
   * Assigns user to experiment variant
   * @param {string} experimentId - Unique experiment identifier
   * @param {string} visitorId - Visitor identifier
   * @returns {string} Variant name ('control' or 'treatment')
   */
  assignVariant(experimentId, visitorId) {
    // Deterministic assignment based on visitor ID hash
    const hash = this.hashString(visitorId + experimentId);
    return hash % 2 === 0 ? 'control' : 'treatment';
  }

  /**
   * Logs experiment event
   * @param {string} experimentId - Experiment identifier
   * @param {string} visitorId - Visitor identifier
   * @param {string} variant - Assigned variant
   * @param {string} eventType - Event type (impression, click, conversion)
   * @param {Object} metadata - Additional event data
   */
  async logEvent(experimentId, visitorId, variant, eventType, metadata = {}) {
    await supabase.from('ab_test_events').insert({
      experiment_id: experimentId,
      visitor_id: visitorId,
      variant,
      event_type: eventType,
      metadata,
      timestamp: new Date().toISOString()
    });
  }

  hashString(str) {
    let hash = 0;
    for (let i = 0; i < str.length; i++) {
      const char = str.charCodeAt(i);
      hash = ((hash << 5) - hash) + char;
      hash = hash & hash;
    }
    return Math.abs(hash);
  }
}

module.exports = new ABTestingService();
```

```sql
-- Question click-through rate by engagement level
SELECT 
  CASE 
    WHEN v.lead_score >= 70 THEN 'high'
    WHEN v.lead_score >= 40 THEN 'medium'
    ELSE 'low'
  END as engagement_level,
  COUNT(DISTINCT e.visitor_id) as total_impressions,
  COUNT(DISTINCT CASE WHEN e.event_type = 'question_click' THEN e.visitor_id END) as clicks,
  ROUND(
    COUNT(DISTINCT CASE WHEN e.event_type = 'question_click' THEN e.visitor_id END)::numeric / 
    COUNT(DISTINCT e.visitor_id) * 100, 
    2
  ) as ctr_percentage
FROM events e
JOIN visitors v ON e.visitor_id = v.visitor_id
WHERE e.event_type IN ('question_impression', 'question_click')
  AND e.timestamp >= NOW() - INTERVAL '7 days'
GROUP BY engagement_level
ORDER BY engagement_level;
```

```javascript
// Full example of hybrid question generation
async function generateQuestionsWithFallback(llmResponse, context, clientConfig) {
  let suggestedQuestions = [];
  
  try {
    // 1. Try to parse LLM response
    const jsonMatch = llmResponse.match(/\{\s*"suggested_questions"\s*:\s*\[.*?\]\s*\}\s*$/s);
    
    if (jsonMatch) {
      const parsed = JSON.parse(jsonMatch[0]);
      const llmQuestions = parsed.suggested_questions;
      
      // 2. Validate LLM questions
      const validation = validateLLMQuestions(llmQuestions, context);
      
      if (validation.isValid && validation.questions.length >= 3) {
        // LLM generated 3+ good questions
        suggestedQuestions = validation.questions.slice(0, 3);
        console.log('[Questions] Using LLM-generated questions');
        
      } else if (validation.isValid && validation.questions.length >= 2) {
        // LLM generated 2 good questions, add 1 template
        const templateQuestions = selectQuestionTemplate(context, clientConfig);
        suggestedQuestions = [
          ...validation.questions,
          templateQuestions[0]
        ];
        console.log('[Questions] Using hybrid approach (2 LLM + 1 template)');
        
      } else {
        // LLM questions failed validation
        throw new Error('LLM questions failed validation');
      }
      
    } else {
      // No JSON found in response
      throw new Error('No JSON found in LLM response');
    }
    
  } catch (error) {
    // 3. Fallback to templates
    console.warn('[Questions] Falling back to templates:', error.message);
    suggestedQuestions = selectQuestionTemplate(context, clientConfig);
  }
  
  // 4. Log for analytics
  await logQuestionGeneration({
    visitor_id: context.visitorId,
    client_id: context.clientId,
    strategy: suggestedQuestions.length === 3 ? 'llm' : 'hybrid',
    fallback_used: suggestedQuestions.length < 3,
    questions: suggestedQuestions
  });
  
  return suggestedQuestions;
}
```

## Appendix B: Migration Guide

### B.1 Backward Compatibility

**Existing Behavior:**
- Questions generated by LLM in same call
- No user context enrichment
- No fallback mechanism

**New Behavior:**
- Questions generated with user context
- Hybrid approach with templates
- Graceful degradation

**Compatibility Strategy:**
- Feature flag for gradual rollout
- Existing code path remains functional
- New code path activated per client

### B.2 Client Migration Steps

**For Each Client:**

1. **Review Current Configuration**
   ```sql
   SELECT client_id, client_name, prompts
   FROM clients
   WHERE client_id = 'target-client-id';
   ```

2. **Add Question Generation Config**
   ```sql
   UPDATE clients
   SET question_generation_config = '{
     "enabled": true,
     "strategy": "hybrid",
     "fallback_behavior": "template",
     "question_count": 3
   }'::jsonb
   WHERE client_id = 'target-client-id';
   ```

3. **Test in Staging**
   - Verify question generation
   - Check personalization
   - Validate fallback behavior

4. **Enable in Production**
   - Start with 10% traffic
   - Monitor metrics
   - Gradually increase to 100%

**If Issues Occur:**

## Appendix C: Performance Optimization

### C.1 Database Query Optimization

**Before Optimization:**
```sql
-- Separate queries (slow)
SELECT * FROM visitors WHERE visitor_id = $1;
SELECT * FROM events WHERE visitor_id = $1 ORDER BY timestamp DESC LIMIT 5;
```

**After Optimization:**
```sql
-- Single query with lateral join (fast)
SELECT v.*, 
  json_agg(e.*) as recent_events
FROM visitors v
LEFT JOIN LATERAL (
  SELECT * FROM events 
  WHERE visitor_id = v.visitor_id 
  ORDER BY timestamp DESC 
  LIMIT 5
) e ON true
WHERE v.visitor_id = $1
GROUP BY v.id;
```

**Performance Gain:** 60-70% reduction in query time

### C.2 Caching Strategy

**User Context Caching:**
```javascript
const cache = new Map();
const CACHE_TTL = 60000; // 1 minute

async function getCachedUserContext(visitorId, clientId) {
  const cacheKey = `${clientId}:${visitorId}`;
  const cached = cache.get(cacheKey);
  
  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    return cached.data;
  }
  
  const data = await enrichUserContext(visitorId, clientId);
  cache.set(cacheKey, { data, timestamp: Date.now() });
  
  return data;
}
```

**Performance Gain:** 90% reduction in database queries for repeat visitors

### C.3 Template Pre-compilation

**Before:**
```javascript
// Templates generated on every request
function selectQuestionTemplate(context) {
```
